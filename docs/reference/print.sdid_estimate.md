# Print an estimate

Prints an estimate on one line, with the name of its estimator, the
effective number of controls, the reciprocal of the sum of the squared
unit weights, the effective number of periods before treatment, the same
for the time weights, and the numbers of treated units and of periods
after treatment.

## Usage

``` r
# S3 method for class 'sdid_estimate'
print(x, ...)
```

## Arguments

- x:

  The estimate to print.

- ...:

  Not used.

## Value

`x`, invisibly.
