# Print an estimate

Prints an estimate on one line: the estimator, the estimate, the
effective numbers of controls and pre-treatment periods (1 / sum of
squared weights), and the numbers of treated units and post-treatment
periods.

## Usage

``` r
# S3 method for class 'sdid_estimate'
print(x, ...)
```

## Arguments

- x:

  The estimate to print.

- ...:

  Not used.

## Value

`x`, invisibly.
